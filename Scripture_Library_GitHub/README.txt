Scripture Library – személyes tanulmányozási prototípus

Feltöltés GitHubra:
1. Csomagold ki a ZIP-et.
2. A három fájlt (index.html, manifest.json, sw.js) töltsd fel a repository gyökérkönyvtárába.
3. GitHub: Settings > Pages > Deploy from a branch > main > /(root) > Save.

Megjegyzés: a teljes Új világ fordítás szövege nincs beépítve. A könyv- és fejezetlista, jegyzetek és könyvjelzők működnek. A jegyzetek a böngésző helyi tárhelyén maradnak. A PWA offline gyorsítótár HTTPS-es tárhelyen működik.
